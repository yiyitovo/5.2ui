# group2-project
Group project about Fintech MakerDAO

As a pioneer of Decentralized Finance (DeFi), MakerDAO has successfully built the DAI stablecoin ecosystem through its decentralized governance and smart contract technology, 
breaking the shackles of the traditional financial model. Our product vision is to continuously improve MakerDAO's system transparency, security and user experience, and 
expand MakerDAO's user base. By continuously optimizing the collateral management, stable coin issuance mechanism and risk control, we are building a more efficient, open and 
trustworthy financial platform to empower global users to achieve truly decentralized financial participation. 

In this project, we will not only focus on core technologies such as DApp development and smart contract optimization, but also record, disseminate and promote our innovative 
journey through video creation, report writing and community promotion. We believe that through continuous iteration and improvement, MakerDAO will be able to set an industry 
benchmark for financial inclusion and autonomy, and inject new vitality into the development of the global digital economy.
